About This Project

EVAL-STATUS: VERIFIED

Contemporary software engineering LLM pipelines fail catastrophically in multi-file repository refactorings due to unchecked context dilution and unconstrained side-effect execution. AgentBench Zero restructures automated bug localization and patch derivation through a bifurcated dual-agent runtime:

psychology Strategic Planner

Decompiles repository AST graphs into dependency sub-trees, isolating candidate files without mutating workspace state. Employs speculative path pruning.

terminal Execution Synthesizer

Executes inside isolated gVisor microVMs with deterministic memory bounds. Synthesizes Unified Diffs, runs integration test harnesses, and validates rollback checkpoints.

By decoupling tree-search reasoning from patch generation, AgentBench Zero prevents infinite recursive hallucination loops and delivers deterministic reproduciblity for high-assurance enterprise codebases.
