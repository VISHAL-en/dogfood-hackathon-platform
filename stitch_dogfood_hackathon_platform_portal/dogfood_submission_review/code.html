Section 02 Architecture Synthesis 418 words · Markdown rendered

AgentBench Zero introduces an explicit separation of intent and tool actuation for high-risk software engineering modifications. Rather than granting code modification permissions to a monolithic language model, the system operates as a bi-directional actor pair:

psychology 1. Strategic Planner (Reasoning Model)

Synthesizes AST diff specifications, unit test invariants, and potential security boundary violations. It emits non-executable JSON schemas containing structured step proposals.

terminal 2. Execution Worker (Deterministic Tooling)

Validates schema steps within an ephemeral gVisor container runtime. Executes git staging, incremental compilation, and deterministic regression replay before committing changes.
