1. Problem & Architecture Motivation

Current agentic code generation harnesses (SWE-bench, HumanEval-X) run untrusted LLM outputs inside permissive environments without verifiable state invariants. As autonomous agents generate higher volumes of multi-file patches, subtle semantic drifts and hallucinated non-deterministic dependencies escape test suites.

AgentBench Zero introduces a dual-containment protocol: every intermediate reasoning trace is compiled into an isolated WebAssembly micro-container where CPU instructions, memory allocations, and network syscalls are captured into a deterministic cryptographic Merkle log.

2. Core Innovations & Implementation

terminal MicroJail Wasm Hypervisor

Sub-12 millisecond cold-start sandboxing built directly on top of Wasmtime. Restricts sys-call primitives to an immutable mock filesystem.

lock_clock Groth16 Trace Attestation

Converts execution state deltas into succinct ZK proofs, enabling peer jurors and downstream continuous integration nodes to verify correctness in under 4ms without re-running code.

hub Universal Agent Driver (UAD)

Native adapters for Claude 3.5 Sonnet, GPT-4o, and DeepSeek-Coder-V2. Standardizes function calling schema and tool orchestration.

dataset Adversarial Canary Suite

Includes 240 deliberately poisoned test vectors targeting symlink path traversal, unbounded memory expansion, and multi-threaded race triggers.

pub fn verify_trace_witness<P: ZkProofEngine>(
    snapshot: &ExecutionSnapshot,
    proof: &P::ProofRecord,
) -> Result<WitnessStatus, VerificationError> {
    // Ensure zero-cycle leakage across sandbox memory borders
    let state_root = snapshot.merkle_commit()?;
    let verified = P::verify_membership(&state_root, proof)?;
    
    match verified {
        true  => Ok(WitnessStatus::Deterministic),
        false => Err(VerificationError::TraceMismatch(state_root)),
    }
}
