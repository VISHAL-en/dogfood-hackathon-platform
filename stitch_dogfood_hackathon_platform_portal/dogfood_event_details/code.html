policy

Rules & Submission Eligibility

Enforced via Automated CI Harness
code 1. Open-Source License & Artifact Format
expand_more

All submitted code must be licensed under Apache-2.0 or MIT. A valid submission requires a public GitHub or GitLab repo containing a root Dockerfile that installs all runtime binaries without external runtime interactive prompts.

replay 2. Deterministic Reproducibility Verification
expand_more

Agents are tested across 3 randomized trial runs on held-out test splits. Submissions showing variance exceeding 12% in success states will trigger a telemetry review. Temperature parameters must be fixed in the configuration manifest.

person_off 3. Zero Human-in-the-Loop Constraint
expand_more

Once the benchmark container receives the input payload through standard STDIN or unix socket, no interactive stdin or outbound human tunnel can be established. Egress ports to unapproved public domains are blocked at the kernel network namespace level.

videocam 4. Required Deliverables & Walkthrough Video
expand_more

Teams must submit: (1) Immutable Git SHA-1 commit hash, (2) Pre-built Docker registry URI tag, (3) A concise 3-minute video walkthrough illustrating internal chain-of-thought traces and architecture diagrams.
